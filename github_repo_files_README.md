# Fuel Theft Analytics & Dashboard

A comprehensive interactive Dash web application and data analysis pipeline for monitoring fuel station transactions, detecting anomalies, and visualizing fuel theft hotspots globally.

## Features
- **Interactive Dashboard**: Built with Dash and Plotly, featuring a custom petroleum-themed dark UI.
- **Geospatial & Trend Analysis**: Interactive global/regional choropleth map, multi-metric temporal trends, and day-of-week breakdown.
- **Live Filtering**: Filter by fuel type, station type, and custom date ranges.
- **Machine Learning Pipeline**: Data preprocessing, outlier detection, and classification models.

## Installation & Running Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/fuel-theft-analytics.git
   cd fuel-theft-analytics
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the app:
   ```bash
   python app.py
   ```
